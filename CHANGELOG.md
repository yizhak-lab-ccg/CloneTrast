# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.1] - 2026-10-01

### Fixed

- README logo, figure, and license badge now use absolute GitHub URLs so they render correctly on PyPI.

## [0.1.0] - 2026-10-01

### Initial release

- Initial public release of CloneTrast.
- Pre-trained contrastive and clone size models hosted on [Figshare](https://doi.org/10.6084/m9.figshare.32228991), downloaded automatically on first use.
- Documentation on Read the Docs, including user guide, API reference, CLI reference, and tutorial notebooks for data preparation and applying CloneTrast.
- Test suite and CI workflow with Codecov coverage reporting.
- Publish workflow releasing to PyPI via Trusted Publishing.
